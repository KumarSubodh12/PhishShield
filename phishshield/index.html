            What is phishing?

            Phishing is when an attacker pretends to be a trusted brand (a bank, UPI app, college portal, Google...) to trick you into typing a password, OTP or card number on a fake page. It is one of the most common ways accounts get hacked, and it works on people, not on computers.

            How the URL analyzer thinks

            It runs a set of rule-based checks on the text of the link and adds up risk points. No machine-learning black box, so every point can be explained:

            • Structure: IP address instead of a domain, hidden @, unusual port, too many subdomains or hyphens, very long URLs.
            • Look-alikes: paypa1.com (digit for letter), rnicrosoft.com (rn for m), typos found with Levenshtein edit distance, and punycode homograph domains.
            • Brand tricks: a brand name placed in a subdomain or path of someone else's domain, compared against a list of genuine domains.
            • Context: risky free TLDs (.tk, .xyz...), URL shorteners, redirect parameters, and pressure words such as verify, kyc, otp.

            How the password lab thinks

            Strength is estimated as entropy = length x log2(character pool), with penalties for sequences, repeats, keyboard walks and years, and a cap when the password is built on a common word. Crack time assumes an attacker who guesses on average half the search space at three different speeds (online, bcrypt, GPU).

            Privacy

            • No server, no database, no analytics. All code runs in your browser.
            • URLs are only parsed as text and never fetched or opened.
            • The optional breach check sends only a 5-character hash prefix (k-anonymity).
            • Scan history is saved in your own browser's localStorage and can be cleared.

            Limitations (be honest!)

            • Heuristics can be wrong. A low score does not prove a link is safe, and a high score does not prove it is malicious.
            • It cannot see the live page, domain age, certificates or reputation feeds. Use Google Safe Browsing or VirusTotal for that.
            • Password entropy is an estimate: uncommon words or names are not in the built-in dictionary, so such passwords can look stronger than they are.

            PhishShield is an educational project. Never enter real passwords into tools you do not trust, including this one.
